# librepaper-wasm-latex

TeX engines (pdfTeX, XeTeX, LuaHBTeX, dvipdfm, BibTeX, BibTeX8, makeindex)
built to WebAssembly for LibrePaper's in-browser LaTeX compiler.

Goal: reproduce the pinned upstream engine release byte for byte from
source, then own the build going forward. See UPSTREAM.md for provenance
and the pinned inputs.
